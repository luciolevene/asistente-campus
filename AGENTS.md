# Asistente Campus

Este proyecto distribuye un asistente académico personal. Para configurar Campus, continuar una entrevista, revisar materias o cambiar preferencias, leer y aplicar `skills/asistente-campus/SKILL.md` como entrada principal. No exigir un prompt especial: interpretar esas solicitudes naturales como activación del asistente.

Si el usuario pide instalarlo en otro proyecto, usar `scripts/install.mjs` según README y verificar la copia. Si quiere usar este propio proyecto, puede comenzar la entrevista aquí sin copiar archivos. Configuración, horarios, respuestas, informes y estado pertenecen exclusivamente a `local/` de la instalación del usuario, excluido de Git. No publicarlos en commits, issues, telemetría o servicios del proyecto; no incorporar credenciales a archivos.

En una solicitud de desarrollo, instalación de archivos o revisión del código, trabajar sobre el paquete y pruebas ficticias. No iniciar una revisión académica real como efecto de desarrollar. Usar `npm test`, `npm run verify` y la prueba incluida para verificar cambios. Mantener Windows/macOS y no introducir dependencias del equipo del autor. Respetar instrucciones y permisos del proyecto de destino.
